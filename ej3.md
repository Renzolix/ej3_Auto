# Ejercicio 3: Auto

## Explicación Lógica
1. **Control de Estado:** El atributo booleano `encendido` actúa como bandera para representar el estado operativo del automóvil.
2. **Métodos `void`:** `encender()` y `apagar()` modifican el atributo `encendido` cambiando el comportamiento interno de la instancia.
3. **Evaluación Condicional:** `mostrarEstado()` utiliza una estructura `if / else` sobre el estado booleano para notificar la situación actual en pantalla.
